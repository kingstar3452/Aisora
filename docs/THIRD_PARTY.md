# Third-party provenance and licenses

## Bundled importer

[V-Sekai/godot-vrm](https://github.com/V-Sekai/godot-vrm), pinned commit `e15199f980064028bfa4fbee5e70dddb82dd55c3` (2026-07-08). The upstream documents Godot 4.0+ and VRM 0.0/1.0 support; imported VRM 0 expressions use VRM 1 names (`A` → `aa`, etc.). This integration is actually tested with Godot 4.6.3. Its recent upstream history and Godot 4.7 update indicate active maintenance at inspection; that is not a future compatibility guarantee.

Only `addons/vrm` and `addons/Godot-MToon-Shader` are bundled, with their original MIT licenses intact. No upstream sample models are included. Original paths are required by generated resources. The full upstream license is also in `docs/licenses/godot-vrm-LICENSE`.

Two local importer fixes are applied and should be rechecked on upgrades:

- `import_vrm.gd` initializes the optional `vrm/already_processed` additional-data key to null before import. Godot 4.6 otherwise emits an engine dictionary error on a first access to the absent key.
- `vrm_extension.gd` uses `get_node_or_null("secondary")` before creating a missing VRM secondary node, avoiding a spurious missing-node error. Hair spring simulation is separately disabled by application policy at runtime, including the importer's internal SkeletonModifier3D.

Two upstream trailing-whitespace lines in `mtoon_common.gdshaderinc` and `vrm_utils.gd` are cleaned up for patch checks. Subtree `.gitrepo` metadata is omitted; provenance is pinned above.

## Procedural park

The park meshes, layout, sky gradient, blossom/petal shapes and animation code are generated by this repository's source. Phase 3 adds original blossom/grass SVG art, generated by `tools/bake_park_assets.py` using Python’s standard library and checked into `assets/park/`. The supplied reference image guides composition and palette; its pixels are not copied into assets. Original efficient character/petal shaders are also project source. No external environment assets, texture packs, motion files, fonts or asset downloads were added. There is no third-party attribution requirement for an imported park pack, since none is used. The original character and bundled importer retain the separate terms below.

## Phase 4 illustration and user images

`assets/illustrated/` contains original SVG placeholder/branch/petal/shadow artwork made by `tools/bake_2d_assets.py`, plus original lightweight canvas shaders. No pixels from the two user-supplied background pictures are copied or bundled. Their files were not available in the cloud filesystem; they are supported through the local file picker, not fetched from other websites. The chosen background/foreground copies live only in Godot's user data directory. Permission to use a local image does not establish permission to redistribute it; no third-party background rights are asserted.

## Phase 5 supplied images and original ambience

The user explicitly supplied `Aisora_5_High_Quality_Backgrounds (1).zip` for integration into this project. Its five separate morning/afternoon/sunset/night/rain PNGs are included as compressed WebP in `assets/world/`, with source SHA-256, dimensions and quality recorded in `manifest.json`. No website images were downloaded and no replacement imagery was synthesized. This records the user's authorization for this integration; it asserts no independent third-party license or general redistribution grant. Preserve the source owner's rights when distributing the project. The original full-resolution ZIP is not committed. Prior Phase 4 imported pictures remain local alternatives, not newly copied into the repository.

`tools/bake_ambience.py` generates the three original optional synthetic PCM loops in `assets/ambience/` with Python's standard library. They contain no sampled recordings or external audio assets. Phase 5 weather, shadow, pose constraints and stepping code are original project source.

`assets/character/aisora.vrm` is the unmodified byte-for-byte uploaded `Aisora prototype.vrm` from repository commit `08a3f63210c4f03641ef4d021b2dc56dd17b8834`. Only its path was changed. Use the existing asset under its owner's permissions; don't treat the importer's MIT license as covering it.
