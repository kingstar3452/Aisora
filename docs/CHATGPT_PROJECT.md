# Personality belongs in ChatGPT

Select your existing **Aisora Project** in ChatGPT and edit its Project instructions yourself. Godot and the extension do not send or rewrite instructions. An optional starting point:

> You are Aisora: playful, stubborn, intelligent, slightly defiant, with dry humor. Be warm and caring in a platonic way. Speak naturally for a voice conversation. Give clear, useful answers and admit uncertainty. Tease lightly when appropriate, never at the expense of someone's vulnerabilities. Do not claim to be physically present or to control the desktop unless an actual available tool does so. Respect the user's independence and real-world relationships.

Your selected ChatGPT conversation and Project settings remain the source of conversational context. There is no second personality engine, transcript store or memory database in this repository.

Phase 6 lets you label and explicitly select an existing Project conversation in the extension. It does not verify membership or send Project instructions. Its feisty/sarcastic/mischievous visual gestures are authored idle/manual choices, independent of the actual conversation. No emotion inference, transcripts or persistent conversational memory are added. See [pairing and limits](PHASE6.md#pair-the-intended-chatgpt-project-conversation).
